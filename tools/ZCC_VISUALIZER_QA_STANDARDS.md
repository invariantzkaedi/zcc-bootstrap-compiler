# ZCC Legendary Visualizer — Behavioral QA Standards

This document establishes the official behavioral verification thresholds and criteria to certify the Zkaedi C-Compiler (ZCC) Celestial Elephant visualizer package as production-ready.

## 1. Timing & State Transition Thresholds
- **Mood Switch Crossfade**: Transitioning between any two mood presets (e.g., `calm_ambient` to `festival_hype`) must complete crossfading within **`180ms`** (defined by `engine.state.transitionMs`). Jerk score must remain below **`0.22`**.
- **Beat Debounce Gating**: No consecutive beat onsets can trigger within **`110ms`** (minimum cooldown interval) to prevent visual double-triggering.

## 2. Macro Scaling Limits
- **Gain Scaling Range**: Composed gain calculation ($finalA = a \times energy \times (1 + 0.25 \times confidence)$) must scale smoothly.
  - At `energy = 0.0`, all reactive translations and sways must scale to `0.0`.
  - At `energy = 2.0`, translations and rotations must not exceed the hard joints clamping boundaries.

## 3. Physics & Priority Solver Stability
- **Arbitration Execution Order**: The modifier execution loop must process exactly in priority order (`pr` ascending) and handle overlapping targets (e.g., `chest` or `tail_root`) using the correct channel override precedence:
  $$\text{ovr} > \text{mul} > \text{add}$$
- **Solver Performance**: The frame rendering loop must maintain a stable **`60 FPS`** (or matches display refresh rate up to `120Hz`) under a full stack of **16+ active modifiers**, with CPU frame times below **`16.6ms`**.

## 4. Gaussian Solver Constraints
- **Wave Speed Propagation**: Ripple radius must propagate at exactly the configured slider speed (pixels/frame).
- **Emissive Filter Caps**: Neon Gaussian filter blurs (`stdDeviation` on `<feGaussianBlur>`) must clamp dynamically between:
  $$\text{Min: } 3.0 \leq stdDeviation \leq 30.0 \text{ :Max}$$
- **NaN/Infinity Protection**: No coordinate, transform, opacity, color matrix, or path attribute values generated by the animation loop may evaluate to `NaN`, `Infinity`, or `undefined`.
