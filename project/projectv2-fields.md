# Recommended ProjectV2 Fields

Create these Single Select fields in your ProjectV2:

1. **Status**
   - Todo
   - In Progress
   - Review
   - Blocked
   - Done

2. **Track**
   - Compiler Core
   - Optimizer
   - Tooling/CI
   - Performance
   - Release/Ops

3. **Milestone**
   - M1
   - M2
   - M3
   - M4

4. **Priority**
   - P0
   - P1
   - P2
   - P3

5. **Size**
   - XS
   - S
   - M
   - L
   - XL

6. **Type**
   - Issue
   - PR
