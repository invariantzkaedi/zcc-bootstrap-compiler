Deploy a resident GPU inference daemon to eliminate weight-load latency, harden C grammar pushdown automata against struct trapping and token leakage, and achieve 100% pass across advanced stress/cryptographic compilation gauntlets.

Root cause:
- Cold weight-load overhead: Loading 1.5B model parameters from disk on every CLI prompt introduced a ~20s latency penalty per run.
