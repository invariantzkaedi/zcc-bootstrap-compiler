feat(posix,stark): implement BabyBear C STARK proof engine and expand native POSIX systems bridge

Goal:
Implement a zero-knowledge BabyBear STARK execution trace attester for C compilations, and expand native POSIX system programming under ZCC with virtual memory (mmap/munmap), IPC pipes, and multiprocessing (fork/waitpid).

Outcome:
BabyBear STARK attestation engine verified across 5/5 cryptographic unit tests with negative control tamper rejection; complete POSIX headers landed under zcc_sys_includes/; dual-suite POSIX gauntlet verified 100% clean under native ZCC compilation; and Gate 1 self-host byte identity sealed.

Root cause:
- Lack of verifiable compilation: Compiler pipelines could not cryptographically prove that machine code accurately represents source AST without full re-execution.
- Missing POSIX systems interface: ZCC lacked unistd.h, fcntl.h, sys/stat.h, sys/mman.h, and sys/wait.h, preventing standalone POSIX systems programming without GCC header dependencies.

Patch summary:
- tools/zk_compiler_stark_attester.py: BabyBear field arithmetic (p = 2^31 - 2^27 + 1), execution trace synthesizer, and SHA-256 binary Merkle IOP verifier.
- tests/test_zk_compiler_stark.py: 5 unit tests validating field algebra, Merkle paths, and tamper rejection.
- zcc_sys_includes/unistd.h: POSIX standard symbols, process IDs, file descriptors, fork, pipe, execve, _exit.
- zcc_sys_includes/fcntl.h: File creation and access mode flags.
- zcc_sys_includes/sys/stat.h: File permissions and type test macros.
- zcc_sys_includes/sys/types.h: Core scalar types (mode_t, dev_t, ino_t, time_t).
- zcc_sys_includes/sys/mman.h: Virtual memory allocation (mmap, munmap, mprotect).
- zcc_sys_includes/sys/wait.h: Process waiting status macros (wait, waitpid, WIFEXITED, WEXITSTATUS).
- tests/test_posix_bridge_native.c: Native POSIX file I/O and PID test.
- tests/test_posix_advanced_native.c: Native POSIX mmap, pipe, and fork/waitpid test.
- tools/run_posix_gauntlet.py: Automated dual-suite POSIX test runner.
- docs/evidence/2026-09-15/stark_posix_milestone/: Complete evidence bundle.
